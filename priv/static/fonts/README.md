# Self-hosted fonts

All four families are free under the SIL Open Font License 1.1 and are
served from here (no Google Fonts request at runtime). `assets/css/app.css`
declares the `@font-face` rules; until a file exists the system fallback
fonts are used.

| File | Family | Weights | Used for |
|---|---|---|---|
| `dm-sans-latin.woff2` | DM Sans (variable) | 400–700 | body text |
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque (variable) | 500–700 | headings, wordmark |
| `dm-mono-500-latin.woff2` | DM Mono | 500 | dates, codes |
| `caveat-latin.woff2` | Caveat (variable) | 600 | polaroid captions |

Source: Google Fonts (latin subset woff2), as published by the font authors.
